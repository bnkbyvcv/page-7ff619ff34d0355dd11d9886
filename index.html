操作说明

第一步：在官网选择套餐

打开 GOOGO 官方网站套餐区，对照流量、设备数与解锁需求下单。支付完成后，账号即生成对应订阅。年付与月付可在同一账户内切换，以当期规则为准。

第二步：复制机场订阅地址

登录后进入用户中心，复制 Clash / 通用订阅链接。不要把订阅发到公开群组。若链接泄露，可在中心重置，旧链接随即失效。

第三步：安装客户端

Windows 与 macOS 常用 Clash Verge、Mihomo 或 Stash；Android 可用 Clash Meta；iOS 常用 Shadowrocket、Stash、Quantumult X。请从各应用自己的发布渠道安装，GOOGO 提供的是订阅而不是来路不明的安装包。

第四步：导入并选择节点

客户端内选择“从 URL 导入”，粘贴订阅。更新节点列表后，按场景挑选：浏览用智能分流，游戏选 IPLC 或低延迟节点，视频选解锁标识节点。开启系统代理或 TUN 模式即可。

第五步：分流与排障

建议打开规则分流，仅对需要加速的域名走代理。打不开网站时先更新订阅、更换节点、检查本地时间与系统代理开关。旗舰与团队用户可通过优先工单提交线路问题。

客户端下载与导入

GOOGO 机场订阅兼容主流加速器客户端，官方下载路径以各客户端项目或应用商店为准。订阅链接只在 GOOGO 官网用户中心发放，导入后即可使用对应套餐的节点池。

桌面端

Windows / macOS：Clash Verge、Mihomo Party、Stash。导入通用订阅后开启 TUN，可覆盖浏览器与多数应用。游戏加速请手动指定 IPLC 相关策略组。

移动端

Android：Clash Meta for Android。iOS：Shadowrocket、Stash、Quantumult X、Surge。商店账号区域可能影响上架状态，请使用可获取该应用的账户，切勿安装未知签名的修改版。

配置要点

保持客户端与内核为较新稳定版；订阅更新间隔不要过短；公司网络若拦截 UDP，可改用 TCP 或对应协议节点。团队版如需定制分流规则，由客户经理协助下发配置片段。

常见问题

GOOGO 是什么服务？和普通 VPN 有何不同？

GOOGO 是机场订阅加 VPN 加速的组合：一份订阅可在多款客户端里使用全球节点，并按套餐提供流媒体解锁与游戏专线。普通单一 VPN 应用往往节点少、策略固定；GOOGO 把线路选择权交给用户，适合需要分流的场景。

如何完成官网下载与客户端安装？

客户端请从其官方渠道下载安装，GOOGO 官网负责发放订阅链接。安装后在客户端选择 URL 导入，粘贴用户中心的机场订阅即可。不要在论坛下载打包“一键连”安装程序，以免账号被第三方截留。

三个套餐该怎么选？流量用完怎么办？

设备不超过 3 台、以网页和基础视频为主选基础版；要原生解锁和 IPLC 选旗舰版；20 台设备或需要专属路由选团队版。月度流量用尽后可升级档位或等待下月重置，具体以用户中心计数为准。

是否支持 Netflix 等流媒体以及游戏加速？

基础版提供基础流媒体解锁；旗舰版与团队版为全节点原生解锁，更适合长期观看。游戏方面，旗舰版包含 IPLC 专线优化，团队版另有 VIP 高带宽节点，延迟表现通常优于普通线路池。

一台订阅能同时登录多少设备？会不会冲突？

基础版 3 台、旗舰版 5 台、团队版 20 台同时在线。超出后新设备可能无法连接或挤占旧会话。家庭共用建议固定设备列表，办公环境用团队版并按部门划分策略组。

节点覆盖哪些地区？线路会变化吗？

常用地区包括香港、台湾、日本、韩国、新加坡、美国与部分欧洲城市。GOOGO 会按负载与质量调整节点，不会把已下线线路长期留在过期列表。请定期在客户端更新订阅。

出现无法连接或速度慢时如何处理？

依次尝试：更新订阅、更换节点、关闭再开启 TUN、检查系统时间、确认没有多个代理软件抢端口。若仅某个网站失败，多半是分流规则问题。旗舰与团队用户可走 7x24 优先工单。
